## Описание программы

Простое графическое приложение (GUI) для генерации случайных задач из предопределённого или пользовательского списка. Приложение позволяет сохранять историю сгенерированных задач и добавлять новые.

### Возможности:
* Генерация случайной задачи по нажатию кнопки.
* Встроенный список задач по категориям (Учёба, Работа, Спорт).
* Добавление пользовательских задач с указанием типа.
* История задач: все сгенерированные задачи сохраняются в файл.
* Фильтрация истории по типу задач.
* Сохранение истории в формате JSON.
* Валидация ввода (проверка на пустую строку при добавлении).

## Инструкция по запуску

### Требования:
* **Python:** Основной язык.
* **Tkinter:** Библиотека для создания графического интерфейса.
* **Random:** Для случайного выбора задачи.
* **JSON:** Для сохранения и загрузки истории.
* **Git:** Система контроля версий.


### Запуск:
1. Убедитесь, что у вас установлен Python 3.
2. Скачайте или клонируйте этот репозиторий.
3. Запустите файл `main.py`:
   ```bash
   python main.py
   ```
4. Приложение откроется в новом окне.

## Примеры использования

### Генерация случайной задачи
1.	Запустите приложение (main.py).
2.	В главном окне нажмите кнопку «Сгенерировать задачу».
3.	В верхней части экрана появится текст с задачей и её типом (например, «Задача: Прочитать статью. Тип: Учёба»).

### Добавление новой задачи
1.	В нижней части окна найдите блок «Добавить новую задачу».
2.	В поле «Задача» введите текст (например, Купить молоко).
3.	В выпадающем списке «Тип» выберите подходящую категорию (например, Отдых).
4.	Нажмите кнопку «Добавить».
5.	Задача появится в истории и будет доступна для генерации.

### Использование истории и фильтра
1.	В центре окна находится список «История задач».
2.	Над списком расположены переключатели (радиокнопки): «Все», «Учёба», «Спорт», «Работа», «Отдых».
3.	Выберите нужный тип (например, «Работа»).
4.	В списке останутся только те задачи, которые относятся к категории «Работа».
